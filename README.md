# colorful animals

Детская HTML-раскраска: 13 животных, семь пастельных цветов, переход после раскрашивания 90% площади животного.

## Запуск

Для сайта: разместите index.html, game.js и папку assets на любом статическом хостинге, в том числе GitHub Pages. Сборка и внешние библиотеки не нужны.

Отдельная автономная версия Colorful-Animals.html открывается прямо в браузере без сервера и интернета.

## Управление

После двух новых заливок одним цветом подряд этот цвет временно блокируется. Выберите другой и закрасьте новую белую область, чтобы снять блокировку. Промахи и перекрашивание не меняют счётчик. Ограничение сохраняется отдельно для каждого животного; сброс раскраски сбрасывает и счётчик.

Go — начать. Нажмите на цвет и область животного. Стрелка вправо открывается после 90%. Круглая стрелка сбрасывает текущую раскраску. Кнопка звука доступна на старте и в игре. Прогресс и звук сохраняются в этом браузере, если доступно локальное хранилище.

Звук синтезируется локально: тихая мелодия, фильтр верхних частот, реверберация. При скрытии страницы, потере фокуса и уходе со страницы аудиоконтекст приостанавливается. Возврат не меняет ручное выключение звука.

## Проверено

Все 13 рисунков: выделение замкнутых областей, исключение внешнего фона, полная заливка; блокировка ниже 90% и открытие следующего животного. Новые рисунки разделены на отдельные участки. Ширины экрана 320 и 390 px, горизонтальный экран 844×390. Логика приостановки и восстановления аудио проверена отдельно; физические iOS/Android устройства не тестировались.

Исходные файлы пользователя не изменены.

## Обновления

Основная ветка: `main`. После изменений публикуйте коммит напрямую в `main`; GitHub Pages обновляет игру автоматически из корня этой ветки.

В репозитории находятся только файлы сайта. Автономный HTML и ZIP — отдельные сборки для скачивания.
